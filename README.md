# 我的右键 (v1.3.6 MV3 Edition)

**我的右键** 是一款专为极致效率设计的浏览器扩展程序。它不仅整合了传统的力量型右键菜单，还引入了现代化的悬浮式选中文标工具栏，旨在将搜索、翻译、知识获取与本地工作流完美缝合。

---

## ✨ 核心功能亮点

### 1. 🍎 iOS 风格悬浮工具栏 (Selection Toolbar)
- **极简设计**：采用 iOS 磨砂玻璃（Glassmorphism）视觉风格，选中文字即现，不干扰阅读。
- **即时功能**：
    - **打开 (直接打开网址)**：智能识别选中文字中的网址，一键新建标签页打开。
    - **Trans (悬浮翻译)**：原地翻译文字为中文，无需跳页。
    - **QR (二维码)**：一键为选中文本生成二维码。
    - **Search (快速搜索)**：默认 Google 快速跳转。
    - **GitHub (代码搜索)**：用选中文字直接在 GitHub 中搜索。
    - **MD / Joplin / Note**：一键触发 Markdown 处理流程。

### 2. 📝 高精度 Markdown 引擎
- **结构化转换**：深度解析 HTML 结构，完美支持**复杂表格**、**多级嵌套列表**、以及**代码块（自动过滤 GitHub 按钮内容）**。
- **GitHub 深度适配**：在 GitHub 仓库主页无选中状态下分享，会自动提取并清洗 **README.md** 正文，秒变专业笔记。

### 3. 📒 Joplin 深度整合
- **API 驱动**：直接通过 Joplin Web Clipper API 交互，稳定高效。
- **云端同步**：支持一键将网页精华以 Markdown 格式同步至 Joplin，自动附带来源 URL 和标题。

### 4. 🔗 增强型复制工作流
- **合并复制 (Merge Copy)**：支持多次“加入合并复制”，最后统一产出。采用 `chrome.storage.local` 技术，即便重启浏览器历史缓冲区也不会消失。
- **记事本直达 (Note)**：选中文本后自动生成临时文件并**调起系统记事本**（或其他默认编辑器）打开，实现浏览器与本地系统的无缝连接。

### 5. 🛠 经典右键菜单能力
- **全能搜索**：集成 Google, 百度, Bing, GitHub 等多引擎。
- **站长工具**：IP 查询、Whois、备案、测速、Ping 测试一应俱全。
- **清理菜单**：所有功能收纳于“我的右键”主入口，保持浏览器右键菜单整洁。

## 🚀 技术特性 (Technical Features)
- **Manifest V3**：完全兼容最新的 Chrome/Edge 扩展规范，更安全、更省电。
- **离屏文档 (Offscreen Document)**：解决了传统持久化后台脚本缺失导致的剪贴板写入不稳定问题。
- **Shadow DOM 隔离**：悬浮工具栏使用隔离的 Shadow DOM 渲染，确保样式不被网页原有 CSS 污染或篡改。
- **异步响应式架构**：所有网络请求（翻译、Joplin API）均采用异步处理，并配有唯一 ID 的通知提醒系统。

## 📥 安装与更新
1. 下载项目源代码。
2. 打开浏览器的“扩展程序”管理页面（`chrome://extensions/`）。
3. 开启“开发者模式”。
4. 点击“加载解压的扩展程序”，选择 `1.3.6` 文件夹。
